# FunVille 🎈

Website for **FunVille** – the ultimate indoor playground for curious, energetic kids.

Made by Dominik Bagoňa.

## How to view it

It's a plain static website (HTML + Tailwind CSS + a little JavaScript), so there's nothing to install:

- **Easiest:** download the repo (green **Code** button → **Download ZIP**), unzip it and double-click `index.html`.
- Or open it through any web server (e.g. MAMP: `http://localhost:8888/funville/`).

An internet connection is needed for the fonts and Tailwind styles.

## What's inside

```
index.html      the whole page
css/            custom styles and animations
js/main.js      menu, scroll animations, counters, FAQ accordion
img/            pictures and logo
```
